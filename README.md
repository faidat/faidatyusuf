# Faidat Yusuf — Portfolio

Personal portfolio for Faidat Yusuf.

## Publish on GitHub Pages
1. Upload `index.html`, `style.css`, and `script.js` to the repository root.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then Save.

With the current repository name, the project-site URL will be:
`https://faidat.github.io/faidatyusuf/`

To use the cleaner `https://faidatyusuf.github.io/` URL later, rename the repository to `faidatyusuf.github.io`.
